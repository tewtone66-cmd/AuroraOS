# updates/hot

Small updates for NexOS (no new APK). Generated by `sh scripts/publish-hot.sh`, do not edit by hand.

- `manifest.json`: `base` (hash of the main page after patches) and, per mod, its `sha` (sha1 of the built mod) and `size`.
- `mods/*.js`: the mods exactly as they are injected into the app (patches already applied).

How it works: the app (scripts/nxhu-runner.js + src/mods/zz-hotupdate.js) compares each mod's sha with the manifest and
downloads only the mods that differ, after checking size and sha1. A downloaded mod replaces the built-in copy.

Limits: only mods can be updated this way. If `src/index.html` (or its patches) changed, `base` no longer matches and the
app says it needs a new APK. Java/native changes always need a new APK. A new APK drops downloaded mods (they are tied to
one APK build). A mod that throws while starting falls back to the built-in copy; an update that stops the app from
starting is removed on the next start.
